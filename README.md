# U2-ejercicio19
### Ejercicio: La Aplicación de Fitness y Seguimiento de Metas

**Objetivo:** Implementar la comunicación entre objetos en Java mediante el envío de mensajes automáticos, permitiendo que una pulsera inteligente notifique al perfil del usuario cuando alcanza una meta diaria de pasos y le otorgue una insignia virtual.

Desarrollo de un sistema de seguimiento de actividad física utilizando las clases `PerfilUsuario`, `PulseraInteligente` y `Main`, aplicando encapsulamiento, listas, validaciones y comunicación entre objetos.
